✎Cómo se mantienen estos manuales

Las capturas de pantalla no son imágenes pegadas a mano: se generan solas desde el sistema. Hay dos formas de usarlas.

Opción A — Automática (recomendada)

Dejás el capturador vigilando mientras trabajás. Cada vez que guardás un cambio en un template, un CSS o un JS, las capturas se regeneran solas:

ComandoQué hace
python manual/tools/capturar.py --vigilarVigila y regenera todo solo.
python manual/tools/capturar.py --vigilar sucursal-metricasVigila, pero solo esa captura.
Cómo trabajar en la práctica

Dejá --vigilar corriendo en una terminal y trabajá en otra. Cada vez que guardes un cambio en la interfaz, en unos segundos la imagen del manual queda actualizada. Solo tenés que acordarte de Ctrl+C al terminar.

Opción B — A pedido

Si preferís recapturar solo cuando vos lo decís:

QuéDónde
Generar todas las capturaspython manual/tools/capturar.py
Regenerar una sola imagenpython manual/tools/capturar.py sucursal-financiero
Controlar calidad de las imágenespython manual/tools/verificar-capturas.py
Generar el PDFpython manual/tools/generar-pdf.py admin-sucursal
Verificar el PDFpython manual/tools/verificar-pdf.py
Editar el texto de un manualEl .html correspondiente en manual/
Estilos compartidosmanual/assets/css/manual.css
Lista de capturas a generarmanual/capturas/manifiesto.json

Para agregar una captura nueva: primero agregala al manifiesto, corré el capturador, y después insertala en el HTML con <figure>.
