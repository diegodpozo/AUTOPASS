AUTOPASS

Sistema inteligente de gestion de estacionamientos que integra reconocimiento automatico de patentes por IA, reservas anticipadas, control de barreras via IoT y panel de administracion en tiempo real.

ALPR + EasyOCR FastAPI ESP32 + MQTT MVP 2 Grupo 404

La Problematica

Problema

Ineficiencia y estres al buscar estacionamiento en zonas urbanas. Los conductores llegan sin certeza de encontrar un lugar disponible, lo que genera demoras, congestion y frustracion. Los procesos actuales son manuales, con pagos limitados y sin herramientas que optimicen la ocupacion en tiempo real.

Impacto

  • Perdida de tiempo y combustible dando vueltas
  • Congestion vehicular en zonas comerciales
  • Experiencia frustrante para el conductor
  • Gestion ineficiente para los operadores
  • Perdida de oportunidades de ingreso

Nuestra Solucion

Autopass

Plataforma integral de gestion de estacionamientos que automatiza el control de acceso mediante reconocimiento de patentes por inteligencia artificial. Transforma un proceso tradicionalmente lento y manual en una experiencia digital fluida, segura y sin fricciones, conectando el software de vision artificial directamente con el hardware de las barreras.

Valor Diferencial

  • Tu auto es tu identidad: No necesitas llevar nada mas que tu vehiculo
  • Gestion en tiempo real: Visualiza disponibilidad antes de salir de tu casa
  • Reservas anticipadas: Asegura tu lugar con semanas de anticipacion
  • Pagos digitales: Sin efectivo ni tarjeta fisica
  • Autogestion total: Controlas tus datos, vehiculos y reservas

Funcionalidades MVP 2

📷

ALPR con IA Completado

Reconocimiento automatico de patentes con EasyOCR + OpenCV. Soporta formatos Mercosur, patentes viejas, motos y deteccion QR. Consenso 2X para evitar lecturas erroneas.

🛡️

Control de Barreras Completado

Integracion con ESP32 via MQTT. Apertura automatica de barrera al detectar una patente valida. Servomotor + sensor ultrasonico HC-SR04.

📅

Reservas Anticipadas Completado

Sistema de reservas por hora, dia, semana, quincena y mes. Aforo diferenciado: reservas de periodo largo reservan plaza fija; reservas por hora usan aforo de paso.

💺

Dashboard Operador Completado

Panel de control en tiempo real con ocupacion, camaras en vivo, apertura manual de barreras y listado de vehiculos ingresados con deuda calculada al instante.

💰

Facturacion Automatica Completado

Calculo de tarifas por bloques de hora con redondeo hacia arriba. Tarifas diferenciadas por tipo de vehiculo (auto, moto, camioneta). Exportacion a CSV.

🔔

Notificaciones In-App Completado

Sistema de notificaciones con polling. Alertas de cambios de ocupacion, eventos de acceso y recordatorios de reserva. WebSockets para actualizacion en tiempo real.

⭐

Fidelizacion y Puntos Completado

Programa de puntos: 10 pts por cada $1000 abonados. Canje de puntos por promociones. Catalogo de beneficios administrable desde el panel.

📊

Reportes Financieros Completado

Reportes de facturacion con filtros por fecha, tipo de vehiculo y metodo de pago. Exportacion a CSV con BOM para Excel. Graficos de recaudacion diaria.

🤖

Lista Negra de Patentes Pendiente

Bloqueo de patentes no deseadas desde el panel administrativo, independiente del estado de la cuenta del usuario.

🏷️

Monitoreo de Salud Parcial

Heartbeat de camaras ALPR y endpoint /health. Pendiente: monitoreo de barreras fisicas (ESP32), broker MQTT y alertas proactivas.

Arquitectura Tecnologica

  • Backend

    FastAPI + Python

    API REST con rutas organizadas por dominio (auth, parking, admin, user, reports). Autenticacion JWT con roles RBAC, base de datos SQLite/SQLAlchemy y tareas en background (Worker) para limpieza automatica de reservas vencidas.

  • Frontend

    HTML + CSS + JavaScript (ES6 Modules)

    Interfaz web responsive con diseno oscuro premium (glassmorphism). JavaScript modular con imports ES6. Comunicacion en tiempo real via WebSockets para ocupacion y camaras en vivo.

  • Hardware

    ESP32 + MQTT

    Microcontrolador ESP32 con sensor ultrasonico HC-SR04, servomotor y display LCD. Comunicacion con el backend mediante protocolo MQTT (broker HiveMQ). Recepcion de comandos OPEN/CLOSE para control de barreras.

  • Vision

    EasyOCR + OpenCV

    Motor de reconocimiento optico de caracteres basado en redes neuronales. Preprocesamiento de imagen con OpenCV (CLAHE, deteccion de bordes, inversion). Correccion heuristica de caracteres y consenso 2X sobre ventana de 4 segundos.

  • Datos

    SQLite + SQLAlchemy

    Base de datos relacional con modelo declarativo. Tablas de usuarios, vehiculos, reservas, accesos, aforo, promociones y configuracion. Migraciones aditivas via init_db(). Preparada para migrar a PostgreSQL en produccion.

  • Infra

    MQTT + WebSockets

    Dos canales de comunicacion en tiempo real: MQTT para comandos de hardware (barreras) y WebSockets para actualizacion de dashboards web. Arquitectura hibrida Edge + Cloud.
