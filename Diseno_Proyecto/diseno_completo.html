📋 Resumen General del Diseño

AUTOPASS es una solución empresarial integral para la gestión inteligente de estacionamientos que combina visión artificial (ALPR), Arquitectura Limpia (Clean Architecture) y un frontend premium para automatizar el control de acceso, facturación y monitoreo en tiempo real de estacionamientos multi-sucursal y multi-piso.

Visión del Sistema

🎯 Propósito

AUTOPASS es una solución empresarial integral para la gestión inteligente de estacionamientos. Combina visión artificial (ALPR), arquitectura limpia (Clean Architecture) y un frontend premium para automatizar el control de acceso, facturación y monitoreo en tiempo real de estacionamientos multi-sucursal y multi-piso.

Problema que Resuelve

❌ Control manual ineficiente
Entrada/salida de vehículos lenta y propensa a errores
❌ Gestión multi-sucursal compleja
Dificultad para gestionar múltiples sucursales y pisos con aforos independientes
❌ Sin visibilidad en tiempo real
No hay forma de conocer la ocupación actual sin recorrer físicamente
❌ Facturación lenta
Procesos manuales propensos a errores de cálculo
❌ Sin reservas anticipadas
Imposibilidad de garantizar plaza sin llegar físicamente
❌ Hardware desintegrado
Barreras, sensores y software funcionando por separado

Glosario de Términos

ALPR
Automatic License Plate Recognition — Reconocimiento automático de patentes mediante visión artificial.
OCR
Optical Character Recognition — Tecnología para extraer texto de imágenes, aplicada a patentes.
ROI
Region of Interest — Región de interés en el frame donde se busca la patente.
MQTT
Message Queuing Telemetry Transport — Protocolo ligero para comunicación IoT con barreras y sensores.
RBAC
Role-Based Access Control — Control de acceso basado en roles (ADMIN, LOCAL_ADMIN, STAFF, USER).
JWT
JSON Web Token — Token de autenticación stateless firmado con HS256.
Aforo
Capacidad máxima de vehículos permitida por piso y tipo vehicular.
MERCOSUR
Formato de patente del bloque suramericano (ABC·1234 o AB·123·CD).
FAB
Floating Action Button — Botón de acción flotante para acceso rápido a funciones principales.
HUD
Heads-Up Display — Superposición de información en feeds de video en vivo.
Glassmorphism
Estilo de diseño UI con efecto de vidrio esmerilado, blur y transparencia.
Clean Architecture
Arquitectura en capas con separación de responsabilidades (Routes/Services/Models/Schemas).
Trimodal
Soporte para tres tipos vehiculares: Auto, Moto y Camioneta con tarifas independientes.
Virtual Time
Sistema de tiempo virtual para cálculos de estadía, configurable en settings.
Heartbeat
Señal periódica de salud enviada por cámaras ALPR para monitoreo de conectividad.

Excluido del Alcance v9.6.0

Los siguientes ítems quedan fuera del alcance de la versión 9.5.0 y serán considerados para versiones futuras:

  • App móvil nativa (iOS/Android)

🚀 Plan de Despliegue

El despliegue de AUTOPASS se realiza mediante scripts automatizados que configuran el entorno, instalan dependencias, inicializan la base de datos y ponen en marcha todos los servicios.

Pasos de Instalación

  1. Clonar repositorio: git clone <repo> && cd autopass
  2. Crear entorno virtual: python -m venv venv && source venv/bin/activate
  3. Instalar dependencias: pip install -r requirements.txt
  4. Configurar variables de entorno: Copiar .env.example a .env y completar SECRET_KEY, SMTP_*, etc.
  5. Inicializar base de datos: python -c "from app import init_db; init_db()"
  6. Ejecutar seed: python seed.py (datos demo)
  7. Iniciar servidor: uvicorn app.main:app --host 0.0.0.0 --port 8000
  8. Iniciar workers: python workers/cleanup_worker.py & python workers/heartbeat_worker.py &

Casos de Prueba Críticos

TC-01: Registro de usuario exitoso

Pasos: Completar formulario con datos válidos → Enviar → Verificar usuario creado en DB

Verificación: HTTP 201, usuario persistido, contraseña hasheada con bcrypt

TC-02: Inicio de sesión con credenciales válidas

Pasos: POST /v1/auth/login con email y contraseña correctos

Verificación: HTTP 200, token JWT en respuesta, token decodificable

TC-03: Ingreso ALPR con patente válida

Pasos: Cámara envía patente → AccessService.validate_entry() → Verificar AccessLog creado

Verificación: AccessLog ACTIVO, ParkingAforo incrementado, mensaje MQTT enviado

TC-04: Salida con pago desde saldo

Pasos: Cámara capta patente en salida → Calcular costo → Descontar saldo → Registrar salida

Verificación: Saldo descontado correctamente, AccessLog COMPLETED, aforo decrementado

TC-05: Cortesía 10 minutos

Pasos: Ingreso ALPR → Salida antes de 10 min → Sin cargo

Verificación: AccessLog con estado COURTESY, costo = 0, saldo sin cambios

TC-06: Reserva exitosa con pago

Pasos: Seleccionar sucursal/piso → Verificar disponibilidad → Pagar desde saldo → Confirmar

Verificación: Reservation PAID, saldo descontado, aforo reservado bloqueado

TC-07: Bloqueo de usuario impide login

Pasos: ADMIN bloquea usuario → Usuario intenta login

Verificación: HTTP 403, mensaje "Cuenta bloqueada"

TC-08: Dashboard en tiempo real

Pasos: Conectar WebSocket /ws/aforo → Verificar mensajes de ocupación

Verificación: Mensajes JSON con datos actualizados cada vez que cambia aforo

📷 Arquitectura ALPR

El módulo ALPR (Automatic License Plate Recognition) es el corazón del sistema de acceso automatizado. Utiliza OpenCV para preprocesamiento de imágenes y un motor dual RapidOCR (ONNX) / PaddleOCR para el reconocimiento óptico de caracteres, con conmutación automática entre motores.

Arquitectura Interna de ALPR

📷 Frame de cámara IPRTSP

🔧 Preprocesador OpenCVGrayscale
▼ frame procesado
📐 Detector de ROIContornos
▼ región candidata
👁️ RapidOCRReconocimiento
▼ texto extraído
🧹 Post-procesadorRegex
▼ patente normalizada

  • Configurar ROI para excluir áreas sin vehículos y mejorar rendimiento
  • Mantener la lente limpia y calibrar periódicamente
